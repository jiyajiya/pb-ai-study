# 파이프라인

**반드시 서브에이전트에게 위임한다.** 메인이 직접 조사하거나 문구를 쓰지 않는다.

메인이 하는 일은 넷뿐이다.
1. 각 단계 결과를 **원본과 대조해 검증**한다
2. 「확인 필요」 중 **메인만 해결 가능한 것**을 처리한다 (담당은 Bash가 없다)
3. 다음 담당에게 **필요한 정보를 실어** 넘긴다
4. **종료 판정**을 한다

**단계를 건너뛰지 않는다.** 특히 카피 없이 검수로 가지 않는다.

## 0라운드 · 고시 조회 (메인이 직접, 위임하지 않는다)
담당은 Bash가 없고, 고시 데이터는 원료 97개짜리 13만 자 JSON이다.
담당에게 통째로 읽히지 말고 메인이 **해당 원료만** 뽑아 준다.

**고시 원문(hwpx·txt)은 이 저장소에 두지 않는다.** 고시에서 오는 값은 전부
`kr-claims/data/kr_claims.json`을 거친다. 원문 갱신 절차는 `kr-claims/README.md`에 있다.

**`kr-claims` 스킬을 호출한다.** 스크립트 경로를 직접 쓰지 마라 — 플러그인으로
설치되면 경로가 `~/.claude/plugins/...` 아래로 바뀐다. 스킬은 자기 위치를 안다.

- 조회 모드로 `{대상}`을 넘기고, 결과를 `research/{대상}-고시.json`에 남긴다.
- 스킬이 목록에 없으면 `kr-claims` 플러그인이 설치되지 않은 것이다.
  0라운드를 건너뛰되 **「규제 확인 필요」를 남기고** 1라운드로 간다.

- 나온 **인정 기능성 문구는 원문 그대로** 다음 담당에게 넘긴다. 한 글자도 다듬지 마라 —
  다듬는 순간 인정받지 않은 표현이 된다.
- `found: false`면 **"인정되지 않음"이 아니다.** 이 파일은 고시형만 담는다.
  개별인정형 목록을 따로 확인해야 하며, 그 사실을 「확인 필요」로 남긴다.
- `functional_claim`이 `null`이면 **"인정 문구가 없다"가 아니다.** 영양성분(1-x, 비타민·
  미네랄) 21종은 고시 템플릿이 달라 이 칸이 비어 있다. 섭취량만 가지고 진행하고,
  문구는 「사람이 현행 고시에서 직접 확인 필요」로 남긴다. **비어 있다고 지어내지 마라.**
- 총론(최소함량 규정)·규격·원료 목록·개정 이력은 이 JSON에 **없다.** 필요하면
  사람이 고시 원문을 봐야 한다는 사실을 「확인 필요」에 적는다.
- `cautions`(섭취 시 주의사항)는 안전 문구의 1차 근거다. 카피 단계에 함께 넘긴다.

## 1라운드 · 조사
`researcher`에게 1단계(규제)만. **0라운드 산출물**(`research/{대상}-고시.json`)을 먼저
보게 한다. 저장소에 고시 원문이 없으므로, 그 밖의 규제 사실은 담당의 웹 조사 몫이다.
→ `research/{대상}.md`

**메인 검증**: 조사 결과의 기능성 문구가 0라운드 JSON과 **글자 단위로 같은지** 대조한다.
담당이 문장을 다듬었으면 되돌린다.

**메인 검증**: 핵심 수치를 원본과 직접 대조. 「확인 필요」 중 메인이 풀 수 있는 것은
직접 해결하고 파일에 「총괄 보강」 주석을 남긴다.

## 2라운드 · 카피
`copywriter`에게 근거를 **파일 경로로** 준다. 공통 규칙은 담당 정의에 있으니
프롬프트에는 **이번 건의 특수 사항만** 쓴다.
→ `copy/{대상}-v1.md`

**안전 정보를 요구할 때 수위를 정해줘라.** "반드시 넣어라"만 쓰면 과하게 이행한다.

## 3라운드 · 검수
`reviewer`에게. **Write 권한이 없으므로 텍스트로 받아 메인이 저장**한다.
→ `review/{대상}-v1-검수.md`

**메인 검증**: 검수 지적을 그대로 믿지 마라. 조문·법령 근거는 직접 확인하고,
틀렸으면 기각하고 저장 파일에 「총괄 주석」으로 사유를 남긴다.

## 4라운드 · 수정
`copywriter`에게 재위임. **새 인스턴스라 v1을 쓴 기억이 없다.**
검수 결과 + 초안 + 근거 **세 파일을 다 읽게** 한다.
기각한 지적이 있으면 "○○는 반영하지 마라"고 명시한다.

## 종료 판정 — 메인이 한다
「지적 0건」을 목표로 하면 끝나지 않는다.

    종료   위험도 '높음' 0건 AND 남은 게 전부 사람 영역
           또는 신규 지적이 전부 '낮음'
           또는 3회차 도달

    이탈   같은 지적이 2회 연속 생존 → 문안 문제가 아니다. 상위 단계로
           신규 '높음'이 회차마다 발생 → 전면 재작성

## 마지막에 반드시
문구가 완성돼도 게시 가능 상태가 아니다. 아래를 체크리스트로 남긴다.

- [ ] 제품 실물 확정 — 품목제조신고번호 / 표시사항의 기능성 내용 / 1회 섭취량당 함량
- [ ] 사전 자율심의 접수 및 심의번호 수령 (근거: 「식품 등의 표시·광고에 관한 법률」 제10조)
- [ ] 판매 주체의 건강기능식품 판매업(유통전문판매업) 신고 확인
- [ ] 게시 직전 현행 고시 재확인

「사람(약무) 최종 확인 필요」를 명시하고 끝낸다.
