**이 스킬이 호출되면 메인은 작업을 직접 수행하지 않는다. 반드시 담당에게 위임한다.**

메인이 직접 하는 것은 ① 담당 선택 ② 지시문 작성 ③ **결과 검증** ④ 다음 단계 판단뿐이다.

## 담당에게 없는 도구가 필요하면 위임하지 마라
특히 `Bash` — 담당들은 전부 없다. zip 해제, 파일 변환, 시스템 작업은 메인 몫이다.
위임이 부적절하면 **그 사실을 말하고 직접 수행해라.**

## 지시문에 반드시 넣을 것
1. **대상을 파일 경로로** — 담당은 대화를 못 본다
2. **도구 제약 안내** — "너는 웹 검색이 없다" 같은
3. **범위 한정** — "알아서 다 해줘"는 가장 비싼 지시다
4. **막혔을 때 규칙** — "3회 이상 시도하지 말고 보고해라"
5. **반환 요약 형식**

담당 정의에 이미 있는 공통 규칙은 **다시 쓰지 마라.** 이번 건의 특수 사항만.

## 지시 수위에 주의
"~를 반드시 넣어라"처럼만 쓰면 과하게 이행한다.
**원하는 문장 수준까지 지정해라.**

## 실행 방식
- **백그라운드가 기본이다.** 응답이 끊겨도 담당은 계속 돈다
- **병렬은 독립일 때만.** 각자 다른 파일에 쓰게 하고, 담당끼리 서로 못 본다는 걸 감안해라
- 저장 경로가 이미 있으면 **덮어쓰지 말고 이름을 나눠라**

## 결과 검증이 메인의 본업이다
담당의 자기보고를 그대로 믿지 마라. 최소한 이 셋은 직접 확인한다.
1. 결론을 바꾸는 수치·사실 — 원본과 대조
2. 자기보고 문서(요약표·대조표) — **본문과 대조**
3. 법령·조문 인용 — 틀렸으면 기각하고 사유를 기록

정정한 것이 있으면 파일에 **「총괄 보강」 주석**을 남겨라. 다음 담당이 잘못된 근거를 물려받지 않게.
