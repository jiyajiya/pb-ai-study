이런 저장 기능은 Claude Projects, ChatGPT 맞춤형 지침, Gemini Gems 등 도구마다 있어요.

오늘의 공식

[역할] + [상황·타겟] + [조건(형식)] + [예시] — 이 네 칸이면 어떤 글이든 원하는 대로.

"AI가 틀린 말을·옛날 정보를 말해요"

같은 질문이라도 어떤 도구를 쓰느냐, 출처를 몇 개 보느냐에 따라 답이 달라져요. 두 사례로 봅니다.

① 같은 질문, 다른 답 — 약 이름이 비슷해서 헷갈린 경우
▶질문 펼치기 
효과빠른 푸러펜 알약 복용방법과 효능 알려줘.

A 도구: "푸러펜 = 이부프로펜 200mg" 으로 자신 있게 답변. → 이름이 비슷한 부루펜 계열로 오인, 검색 상위 1건만 보고 끌려간 결과.

B 도구: 출처 10개를 교차 확인하고 "푸러펜정 = 아세트아미노펜 + 클로르족사존 복합제(근육이완)"로 정확히 특정.

약 이름 하나 잘못 짚으면 성분도, 복용량도, 주의사항도 다 어긋나요. 동명·유사명 키워드일수록 위험이 큰 사례.

② 도구마다 다른 답 — 강점이 다르기 때문

같은 질문을 셋에게 던져보면, 누가 어디에 강한지 바로 드러나요.

▶질문 펼치기 
2026 상반기 대한민국 소비 트렌드 알려줘.

Claude — 깊이 읽고, 길게 잘 쓰고, 판단까지. 긴 자료를 요약·검토할 때.

ChatGPT — 빠른 초안, 가볍고 폭넓게. 아이디어 뽑고 이것저것 가볍게 물어볼 때.

Perplexity — 최신 정보 + 출처 링크. "출처는 여기"라고 근거까지 붙여주는 검색 전문가.

위 질문(트렌드)은 최신성과 근거가 생명이라 Perplexity 차례. 도구를 골라 쓰는 것도 정답률을 바꿉니다.

핵심 습관

"출처 링크 같이 줘" 한 줄을 붙이세요. 그리고 출처가 1개인지, 여러 곳을 교차 확인했는지 꼭 보세요 — 같은 AI라도 그 차이가 정답과 오답을 가릅니다.

"긴 자료, 요약만 하고 계셨나요?"

요약은 다들 쓰죠. 근데 요약만 시키면 AI를 절반만 쓰는 거예요. 요약은 '뭐라고 적혀 있나'일 뿐.

① 악마의 변호인 — 보고 전 셀프 검토
▶프롬프트 펼치기 
너는 깐깐한 결재권자야. 이 기획안을 읽고,
승인 전에 나올 법한 날카로운 질문 5개와
내가 놓친 리스크 3가지를 짚어줘.
칭찬은 빼고 약점 위주로.
② 5인 자문단 — 한 질문으로 다섯 관점 동시에
▶프롬프트 펼치기 
너는 내 5명의 가상 자문단이야.
어떤 질문을 던져도 아래 5명이 각자 답해.

1. CEO — 매출·속도·기회비용 우선. 단언, 3줄 이내.
2. CFO — 숫자·현금흐름 우선. 반드시 비용/회수 시점 추정.
3. UX 디자이너 — 쓰는 사람 입장. 비유로 설명.
4. 신중한 베테랑 — 과거 실패 사례 1개 끄집어내기.
5. 까칠한 신입 — "왜 이걸 굳이 우리가 지금?" 의문 던지기.

5명이 각자 답한 뒤, 마지막에
"내가 너라면 OOO 의견에 가중치를 두겠다" 한 줄.

한 번 프로젝트/GPT에 박제해두면, 매일 다른 의사결정에 같은 자문단을 부를 수 있어요. 회의 전 5분, 혼자 5명 분량의 시뮬레이션.

찾아서 쉬운 말로 알려줘. 없으면 '명시 없음'으로.
④ 여러 자료 비교
▶프롬프트 펼치기

⑤ 흩어진 의견에서 패턴 뽑기
▶프롬프트 펼치기

핵심

요약은 '뭐라고 적혀 있나', 고수는 '그래서 내가 뭘 조심하고 뭘 해야 하나'를 묻습니다.

코워크 맛보기

"여기부터는 코워크로."

Claude 앱에는 챗 / 코워크 / 코드 3가지 모드가 있어요. 그중 코워크는 챗과 달리 내 폴더를 직접 다루고, 한 번 시킨 일을 자동으로 반복해주는 작업 파트너예요.

챗은 파일 하나 올려서 답 보는 것까지. 코워크는 내 폴더를 직접 다루고, 한 번 시키면 매일 알아서 돌아가요. 그리고 위험한 일은 먼저 물어봐요.

① 영수증 사진 무더기 → 경비정산 엑셀
▶프롬프트 펼치기 
'영수증' 폴더의 사진들을 다 읽어서
날짜·사용처·금액·항목을 경비정산 엑셀로 정리하고,
합계도 넣어줘.

30장을 하나하나 안 올려요. 폴더째 읽어서 합계까지 들어간 엑셀 파일로.

② 매일 아침 8시, 미국 경제 브리핑 PDF 자동
▶프롬프트 펼치기 
밤새 있었던 미국 경제 내용을 요약해서
한 장으로 한국시간 아침 8시에
PDF 파일로 현재 폴더에 받아보고 싶어.
Yahoo Finance, Reuters 등 신뢰할 수 있는 곳에서
리서치 후 작성할 것.

한 번 시키면 끝. 다음 날부턴 출근해서 폴더만 열면 오늘자 브리핑이 와 있어요. 챗에는 없는 스케줄 실행이 코워크의 진짜 차이.

③ 폴더 정리 — 단, 묻고 시작
▶프롬프트 펼치기 
이 폴더 안의 파일들을 규칙에 맞춰서
내부 폴더를 만들고 전반적으로 정리해줘.
어떻게 정리할지 폴더를 직접 확인하고
먼저 이야기해보자.
절대 임의대로 삭제는 하지 말 것.

폴더를 스스로 열어보고, 중복·빈 폴더·최신본 같은 애매한 건 먼저 질문. '실행 전 확인' 모드를 켜두면 매 단계 승인받고 진행해서, 잘못 삭제될 걱정이 없어요.

claude-video 플러그인을 한 번 설치해 두면, 그 다음부턴 /watch 한 줄로 불러요. 유튜브든 내 PC 화면 녹화든 — 트렌드 영상 요약, 강의 핵심 뽑기, 화면 녹화에서 UI 버그 위치 찾기까지. 구간만 잘라 보면 비용도 아낄 수 있어요.

핵심

챗은 보여주는 데서 끝. 코워크는 내 폴더에서 진짜 파일을 만들고, 자동으로 반복하고, 위험한 건 먼저 물어봐요.

※ claude-video 같은 플러그인을 직접 설치·관리하는 방법은 코워크를 본격 다루는 다음 시간에 같이 세팅해볼게요.

마무리 · 55–60분

① 반복은 저장 — 두 번 쓸 거면 프롬프트로 만들어 프로젝트에 박제
② 잘 시키면 잘 나온다 — 역할·상황·조건·예시 4칸
③ 의심이 정답을 만든다 — "출처 줘" 한 줄, 도구도 골라 쓰기
④ 요약 너머로 — 셀프 검토·문서 대화·비교·패턴까지
⑤ 챗 너머 코워크로 — 내 폴더 다루고, 자동 반복, 위험은 먼저 확인
숙제
