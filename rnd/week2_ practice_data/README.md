## 구성

| 파일/폴더 | 쓰는 실습 (STEP 4) | 청중 표시 | 의도 |
|---|---|---|---|
| `회의메모/` (txt 3개) | 폴더째 회의록 정리 | 오늘 같이 | PharmaBros R&D 맥락의 지저분한 실제 메모. 미정·미결 항목 포함 → "지어내기 금지" 규칙 확인 |

- 영수증 실습에서 05번이 '(판독 불가)' 목록에 들어갔는지 확인 → "AI가 모르는 걸 모른다고 하게 만드는 규칙"의 효과
