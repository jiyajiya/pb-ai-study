개념 1기반

옵시디언 — 내 메모 앱

모든 것의 바탕이 되는 메모 앱. 먼저 이 위에 다른 기능들이 얹혀요.

내 노트를 마크다운(.md) 파일로 내 PC에 저장하는 메모 앱
클라우드 강제 없음, 업체 종속 없음 → 내 데이터는 온전히 내 것. 노트끼리 [[링크]]로 잇고 그래프 뷰로 연결을 본다 — 이게 위키의 기반.
한 줄 — 내 PC에 저장되는 메모 앱. 이 위에 Smart Connections·Copilot·LLM Wiki가 얹힌다.
개념 2·3임베딩 · Smart Connections

의미로 찾는다 — 비슷한 노트 자동 발견

먼저 모든 기능의 바탕인 '임베딩'을 알고, 그 위에서 Smart Connections를 봅니다.

임베딩 (벡터화) — 기초 개념
노트를 "의미 좌표(숫자 묶음)"로 바꾸는 것
컴퓨터가 글의 '뜻'을 비교하려면 숫자로 바꿔야 함. 의미가 비슷한 노트는 좌표 공간에서 가까이 위치하게 됨.
비유 — 모든 노트를 '의미 지도' 위에 배치하는 작업. 이게 의미 검색의 바탕.
Smart Connections — 의미 기반 노트 연결
지금 열어둔 노트와 의미가 비슷한 노트를 자동으로 찾아 보여줌
키워드가 아니라 의미로 찾음. "약사" 노트를 열면 단어가 안 겹치는 "복약지도·조제"도 떠올려줌. API 키 없이 로컬 실행 — 노트가 PC를 안 떠남.
한 줄 — "이 노트랑 비슷한 거 어디 있지?"를 자동으로.
핵심

임베딩으로 노트를 의미 좌표로 바꿔두면, Smart Connections가 키워드 없이도 비슷한 노트를 알아서 찾아줘요.

개념 4·5RAG · Copilot

노트와 대화하듯 검색

Copilot이 '어떻게' 내 노트로 답하는지(RAG)를 먼저 알면 한계도 이해돼요.

RAG — Copilot이 답하는 방식

RAG = Retrieval-Augmented Generation (검색 증강 생성)

1문서를 조각으로 분할
2조각을 벡터(숫자)로 변환 (임베딩)
3질문과 비슷한 조각을 검색
4그 조각을 근거로 AI가 답변 생성
비유 — 문서를 잘게 쪼개 저장해두고, 질문하면 관련 조각만 찾아 답한다. 같은 방식: NotebookLM, ChatGPT 파일 업로드
Copilot — 노트와 대화
옵시디언 안의 AI 대화 인터페이스 (ChatGPT 같은 채팅창)
볼트 전체 AI 검색 / 에이전트 모드 / PDF·유튜브·웹 이해. 위의 RAG 방식으로 내 노트를 근거로 답함. 모델은 OpenAI·Anthropic·Google·로컬 선택.
한 줄 — 볼트 전체를 AI와 대화하듯 검색.
핵심

Copilot은 내 노트를 RAG로 검색해 답해요. 조각을 찾아 답하기 때문에 '콕 집은 질문'에 강합니다.

개념 6가장 중요핵심

RAG가 못 하는 질문이 있다

RAG에는 잘하는 질문과 못하는 질문이 있어요. 이걸 알아야 다음의 LLM Wiki가 왜 필요한지 이해됩니다.

✅ 로컬 질문
"카파시가 뭐라고 했어?"
특정 부분을 콕 집어 묻기 → 관련 조각만 찾으면 됨 → RAG가 잘함
✖ 글로벌 질문
"전체적으로 무슨 흐름이야?"
전체의 공통 패턴·흐름은? → 조각 검색으론 전체를 못 봄 → RAG가 막힘
비유 — RAG는 "페이지는 찾지만, 책 전체 요약은 못 함". 예: "논문 50개의 공통 트렌드는?" → RAG는 답 못함.
핵심

RAG(Copilot)는 콕 집은 '로컬 질문'은 잘하지만, '전체 흐름'을 묻는 글로벌 질문엔 막혀요. 이 한계를 푸는 게 LLM Wiki.

개념 7·8LLM Wiki · Ollama오늘 같이

넣을 때 정리해서 쌓인다

RAG가 질문할 때마다 검색한다면, LLM Wiki는 넣을 때 미리 정리해서 쌓아둬요. 그래서 글로벌 질문까지 답합니다.

LLM Wiki — 자동으로 위키가 되는 지식 창고
노트를 자동으로 위키 페이지로 정리·축적하는 도구
자료를 넣으면(ingest) AI가 읽고 개념·인물 페이지를 만들고 서로 링크까지 검. 미리 종합돼 있으니 "전체 흐름은?" 같은 글로벌 질문에도 답함.
두 가지 질문 처리 방식
로컬"카파시가 뭐 했어?" → 해당 엔티티(노드)를 찾아 주변 관계를 따라감 (카파시 → 테슬라 → OpenAI …)
글로벌"전체 흐름은?" → 여러 페이지 요약을 종합해 큰 그림을 답함
Ollama — 이 모든 걸 돌리는 로컬 엔진
내 컴퓨터 안에서 AI(LLM)를 무료로 돌려주는 엔진
인터넷·API 키·비용 없이, 데이터가 PC를 안 떠남(민감 정보에 안전). Copilot·LLM Wiki가 이 엔진을 불러 AI 작업을 시킴.
도구지식 축적데이터 소유
ChatGPT✖ 대화 종료 시 소실OpenAI 서버
NotebookLM△ 매번 재검색Google 서버
LLM Wiki✅ 투입 시 정리·축적로컬 마크다운(내 PC)
오늘 제일 중요한 한 줄

"LLM Wiki는
넣을 때 정리해서 쌓여요"

RAG가 못하던 '큰 그림' 질문이, 미리 종합해 쌓아두면 가능해져요.

마무리 · 오늘의 핵심 8

① 옵시디언 = 내 메모 앱 (내 PC에 저장)
② 임베딩 = 노트를 의미 좌표로 변환 (모든 기능의 바탕)
③ Smart Connections = 비슷한 노트 자동 발견
④ RAG = 조각 검색으로 답하는 방식 (로컬 질문에 강함)
⑤ Copilot = 노트와 대화 (RAG 방식)
⑥ 로컬 vs 글로벌 질문 = RAG는 '콕 집은 질문'엔 강하지만 '전체 흐름'은 못함
⑦ LLM Wiki = 넣을 때 정리해 쌓아서 전체 흐름까지 답함
⑧ Ollama = 이 모든 걸 내 PC에서 무료로 돌리는 엔진
